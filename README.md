# EnlacePro Landing

Sitio público simple de EnlacePro.

## Estructura

- `index.html`: landing principal.
- `privacidad.html` y `terminos.html`: páginas legales.
- `assets/css/`: estilos.
- `assets/js/`: JavaScript.
- `assets/php/send-contact.php`: envío del formulario.
- `assets/brand/`: identidad visual.
- `assets/img/`: imágenes.

## Requisitos del servidor

- Servidor web.
- PHP con `mail()` habilitado y transporte de correo configurado en el VPS.

No usa Laravel, Composer ni dependencias PHP externas.
